# P2 d=2 rotation-invariance protocol

This document freezes a numerical coordinate-equivariance sanity test for the previously
validated d=2 stochastic-SCAFFOLD system. The machine-readable contract is
`configs/d2_rotation_invariance.yaml`. No rotation trajectory or result artifact is generated by
this freeze.

## Protocol amendment note

The original rotation protocol was committed before any rotation result was observed. P2-I3b
pre-flight identified that the communication-round horizon had not been specified, and no rotation
simulation had been run at that time. This amendment freezes `T=200` before any rotation execution.
No other scientific choice, matrix, seed, tolerance, theory target, or gate is changed.

## Coordinate transformation

Use the 30-degree orthogonal rotation

```text
theta = pi / 6
Q = [[0.8660254037844386, -0.5],
     [0.5,                 0.8660254037844386]].
```

With `y = Q x` and `x = Q.T y`, the rotated representation is the same mathematical objective:

```text
f_rot(y) = f(Q.T y)
         = 0.5 y^T A_rot y + alpha psi(u_rot^T y),
grad f_rot(y) = Q grad f(Q.T y).
```

The gradient identity is a mandatory implementation and test requirement. The original and
transformed parameters are

```text
A = [[1.2, 0.2],                 A_rot = [[0.976794919243112, 0.186602540378444],
     [0.2, 1.0]],                         [0.186602540378444, 1.223205080756888]],

C = [[1.0, 0.2],                 C_rot = [[0.751794919243112, 0.229903810567666],
     [0.2, 0.7]],                         [0.229903810567666, 0.948205080756888]],

u = [0.7071067811865475,         u_rot = [0.258819045102521,
     0.7071067811865475],                 0.965925826289068],
alpha = 0.25.
```

The original and transformed commutator Frobenius norms are both
`0.028284271247461926`. Thus the orthogonal similarity keeps the formal example genuinely
noncommuting.

## Paired noise rule

For each seed, communication round, local step, and client, generate the original block once:

```text
epsilon = cholesky(C) z,
epsilon_rot = Q epsilon,
```

where the coordinates of `z` are Rademacher. Feed `epsilon` to the original system and the
matched `Q epsilon` to the transformed system. This gives
`Cov(epsilon_rot) = Q C Q.T = C_rot` pathwise from the shared realization.

Generating `cholesky(C_rot) z_rot` independently, or taking any fresh transformed draw, is
forbidden. Rademacher noise is not rotationally invariant, so such a construction would not test
coordinate equivariance of the same stochastic realization.

## Paired matrix and initialization

Use `d=2`, `H in {2,4}`, both `(N=16, gamma=1/16)` and
`(N=64, gamma=1/64)`, and seeds `1101`, `1102`, `1103`, and `1104`. The Cartesian product has
16 paired runs. Each pair contains one original-coordinate system and one transformed-coordinate
system driven by exactly matched noise blocks. These seeds are disjoint from the earlier formal
P2 matrices.

The fixed pathwise horizon is `T=200` communication rounds per paired run. Every one of the 16
pairs uses exactly this horizon, with no burn-in, stationary batching, adaptive horizon, stopping
rule, or seed-dependent horizon.

Initialize with

```text
x0 = [0.2, -0.1],
x0_rot = Q x0 = [0.223205080756888, 0.013397459621556],
xi_c = xi_rot,c = 0 for every client.
```

The nonzero global state supplies a deterministic transformation check before stochastic
stationarity.

## Pathwise gate

For every pair, the expected identities are `x_rot,t = Q x_t`,
`xi_rot,c,t = Q xi_c,t`, and `qbar_rot,t,h = Q qbar_t,h`. If the local endpoint is already
exposed without scientific changes, also check `theta_rot,c = Q theta_c`; storing additional
local trajectories solely for this test is not required.

Define

```text
r_x    = max over t=1,...,200
         ||x_rot,t - Q x_t||_infinity
r_xi   = max over t=1,...,200 and clients c
         ||xi_rot,c,t - Q xi_c,t||_infinity
r_qbar = max over t=1,...,200 and local steps h
         ||qbar_rot,t,h - Q qbar_t,h||_infinity.
```

Record every per-pair value and the global maxima. Every pair must satisfy
`max(r_x, r_xi, r_qbar) <= 1e-10`. The threshold may not be loosened after results are seen.

When naturally available from the same rounds, `b_hat_rot approximately Q b_hat` and
`C_hat_rot approximately Q C_hat` may be recorded as secondary diagnostics. They do not justify
a new long stationarity experiment, and coefficient agreement cannot replace the primary
pathwise gate.

## Interpretation boundary

If every theory and pathwise gate passes, the permitted empirical and numerical sanity conclusion
is: “The implementation and theoretical coefficient are equivariant under the pre-registered
30-degree orthogonal coordinate transformation.”

The exact algebra supplies the mathematical coordinate transformation; the numerical test checks
implementation and representation consistency. It is not a new theorem proof, an additional
coefficient validation, or evidence for every coordinate transformation. It makes no claim about
a different noise law, d=5, or heterogeneity.
