# Repository preparation materials for the targeted mechanism study

These archives are exact copies of the supplied result/source packages. They are
not included in the typeset paper and have not been pushed to GitHub.

The manuscript uses the frozen primary rows in
`TARGETED_MECHANISM_REVIEW.zip::results/primary_family_36.csv`. Main Table 4 and
Appendix Table 12 partition those rows, with the paired signed-covariance
contrast in Appendix C.2.5. The complete grid, windows, restricted fits,
resampling sensitivities, numerical flags, and original precision remain in
the review ZIP. The source ZIP contains the independently selected trigonometric
model/kernel, frozen protocol and analysis scripts. Primary source references
and limitations are documented in the supplied literature audit.

The earlier independent review/audit is retained as an additional record, not
as a new analysis performed during this manuscript integration. No production
results, target-inclusion outcomes or published-repository status were changed.

## Scientific scope

Paired null and covariance-matched law comparisons reached the prespecified
fitted-coefficient resolution. Individual-algorithm first-coordinate null and
law contrasts remain less resolved. Sampling intervals do not include burn-in
or deterministic grid error. All reported sensitivities remain available.
